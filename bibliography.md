# Tonton Project - Comprehensive Bibliography

This bibliography contains all academic citations found in the Tonton codebase, organized alphabetically by first author's last name. Citations are drawn from the physics-based biological simulation modules for fish, birds, reptiles/amphibians, mammals, arthropods, and mollusks.
